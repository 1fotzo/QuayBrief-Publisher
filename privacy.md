# QuayBrief Publisher privacy policy

QuayBrief Publisher is a private tool used by one shop, QuayBrief, to create Pins on its own Pinterest boards. It stores a Pinterest access token on the owner's computer, plus the board id and the id of each Pin it creates. It reads that account's own boards and pins so it can post to the right board and avoid posting the same image twice. It does not collect information about other Pinterest users, it does not sell data, and it does not share the token. Contact is the QuayBrief Etsy shop at https://www.etsy.com/uk/shop/QuayBrief.
